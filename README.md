# render-cn-tools（中文“同义改写”前端小工具）

纯前端实现，零后端依赖，适合直接部署到 **Render** 的 Static Site。

核心能力：
- **约定俗成词表（首选）**：互联网通用表达，来源为维基百科「拼音缩写」、网络缩略语大全、中文网络词规范化数据集等
  - 拼音缩写：笑死我了→xswl、永远的神→yyds、你说得对→nsdd、有一说一→u1s1、对不起→dbq、太强了→tql、不懂就问→bdjw、啊我死了→awsl、小姐姐→xjj、微信→wx…
  - 谐音字词：什么→神马、这样子→酱紫、不知道→布吉岛、难过→蓝瘦、想哭→香菇、朋友→盆友、同学→童鞋、喜欢→稀饭、睡觉→碎觉、吃饭→次饭、非常→灰常…
- **数字梗替换**：厉害→666、拜拜→88、我爱你→520、一生一世→1314、气死我了→7456、救救我→995、傻瓜→62、我生气了→5376…
- **同音/错别字替换**（政府→振府、检查→捡查、监控→见控…）
- **通用拼音/字母兜底引擎**（任意未覆盖汉字→拼音/首字母/混搭）
- **小范围字序微颠倒**（方案→案方 这类，保证一眼能懂）
- **保护机制**：已替换的约定词（酱紫、盆友、布吉岛…）不会被后续字序颠倒/随机拼音二次破坏
- 改写强度 1~10 可调

## 本地预览

直接双击 `index.html` 打开即可；或在该目录启动任意静态服务：

```bash
python3 -m http.server 8080
```

然后打开 `http://localhost:8080`。

## Render 部署

1. 把这个文件夹 push 到 GitHub（公开/私有都可）。
2. Render → New → Static Site。
3. Build Command 留空，Publish Directory 填 `.`（或 `render-cn-tools`，看你 repo 结构）。
4. Deploy 后即可获得一个公开可访问链接。

> 因为是纯静态站点，无后端进程，免费方案即可。
